# Diretório de Relatórios de Code Review

Este diretório armazena os relatórios estruturados gerados pelas execuções do workflow `/code-review`.

## Convenção de Nomenclatura dos Relatórios
Os relatórios devem seguir o padrão:
```
.agents/reviews/YYYY-MM-DD_[task-slug]_review.md
```

Exemplo:
- `.agents/reviews/2026-09-17_melhorias-sistema-pontuacao_review.md`

## Estrutura do Relatório
Consulte o formato obrigatório definido em `[code-review.md](file:///c:/projects/beach-tennis-ap/.agents/workflows/code-review.md)`.
